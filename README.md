# Interaktives Z (Partikel-Effekt)

Ein kreatives Web-Projekt, bei dem hunderte Partikel die Form des Buchstabens "Z" bilden. Im Ruhemodus wabern die Punkte dynamisch hin und her. Sobald man mit der Maus über das "Z" fährt, fliegen die Partikel elegant auseinander und kehren danach wieder an ihren Platz zurück.

## 💡 Die Story hinter dem Projekt

Ich lerne gerade das Programmieren und bin noch am Anfang meiner Reise. Auf der Webseite [zollsoft.de](https://zollsoft.de/) habe ich diesen genialen Partikeleffekt gesehen und war sofort total fasziniert! 

Weil ich unbedingt wissen wollte, wie so etwas im Code aussieht und wie die Logik dahinter funktioniert, habe ich mir für die Umsetzung Hilfe von einer **KI** geholt. Gemeinsam haben wir den Code Schritt für Schritt aufgebaut, verfeinert (für gerade Kanten und perfekte Abstände) und animiert. Dieses Repository dient für mich als Lernprojekt, um die Welt von HTML5 Canvas und JavaScript besser zu verstehen.

## 🚀 Funktionen

* **Perfekte Form:** Das "Z" hat saubere, gerade Außenkanten und die Partikel sind absolut gleichmäßig verteilt.
* **Maus-Interaktion:** Partikel flüchten smooth vor dem Mauszeiger (Gummiband-Effekt).
* **Organischer Ruhemodus:** Wenn die Maus weg ist, bewegen sich die Partikel lebendig und dynamisch von alleine.
* **Reines Web-Tech:** Komplett ohne schwere Bibliotheken geschrieben (nur HTML, CSS und Vanilla JavaScript).

## 🛠️ Wie man es startet

1. Lade dir die Dateien herunter (oder clone das Repository).
2. Öffne die `index.html` einfach mit einem Doppelklick in einem beliebigen Webbrowser (Chrome, Firefox, Safari, Edge).
3. Bewege die Maus über das "Z" und schau, was passiert!
